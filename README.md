# Weather-tracker
This is a REST API movie watchlist website for a University final project, How it works is you go to the watchlist page and you type a movie into the input field, accept terms and conditions then add the movie.
The api will search for the closest match to the movie you searched and create a table featuring the movie name, description and release date. This also works for TV shows
